# Lekcja 2: Klonowanie i praca na zdalnym repozytorium

Klonowanie istniejącego repozytorium z serwera GitHub, konfiguracja danych autora, tworzenie plików oraz synchronizacja zmian.




## Używane komendy:

- cd <sciezka> – przejście do wskazanego folderu (np. cd .. lub cd kopia_repo).
- mkdir <nazwa> – utworzenie nowego folderu.
- ls – wyświetlenie listy plików i folderów w katalogu.
- ls -a – wyświetlenie wszystkich plików, w tym ukrytych (np. folderu .git/).
- git clone <URL> – klonowanie istniejącego repozytorium ze zdalnego serwera na lokalny komputer.
- touch <nazwa_pliku> – utworzenie nowego, pustego pliku (np. touch drugi_użytkownik.txt).
- git branch – wyświetlenie listy lokalnych gałęzi (gwiazdka * oznacza aktualną gałąź).
- git config user.name "Imię Nazwisko" – ustawienie podpisu autora dla commitów (używaj spacji, nie znaku =).
- git config user.email email@example.com – przypisanie adresu e-mail do autorstwa commitów (używaj spacji, nie znaku =).
- git add <nazwa_pliku> – dodanie konkretnego pliku do poczekalni (staging area).
- git commit -m "wiadomość" – zapisanie zmian znajdujących się w poczekalni jako commit z opisem.
- git log – historia zapisanych commitów (hashe, autorzy, daty i opisy).
- git push – wysłanie zcommitowanych zmian ze swojej lokalnej gałęzi do zdalnego repozytorium na GitHubie.
- git pull – pobranie i scalenie najnowszych zmian ze zdalnego repozytorium do aktualnej gałęzi lokalnej.
